日期：2026-10-28 至 29。实现以 `Documentation/Research/ToonLive/` 的数学审阅和隔离 GPU 结果为依据；以下清单在实际检查后更新，源码存在不等于画面通过。逐项结果见 [本轮验证](ValidationReport.md)。

## 本轮目标

1. 把既有五个 Toon 参数从统一风格资产解析到原生 Substrate Toon 后端。着色模型是可选配置，保留普通受光与继承原模型。
2. 在现有 NPR 调制工作区增加 Toon 页面：左侧参数和小曲线、中央角色预览、真实模型区域点选与 Section/材质槽列表、保存与应用。
3. 验证不可变资源的运行时绑定、失败原子性、外部材质保护与重开；用实际 GPU 数据验证刷新与误差。
4. 合并交互更新，保留资源所有权、撤销/重做、原始高级 Profile 控制和既有 Rim/Outline/Surface 组合。
5. 同步原始 Documentation、网页 docs、变更记录和源码快照，完成文档构建及本地页面检查。

## 质量边界

漫反射的坐标转换和生成曲线可以单独检验，最终外观仍受原生 LUT、阴影和光照调度影响。高光采用各向同性 GGX 的参考角域映射，受 NoV 能量查表、灯型和外层受光影响；要记录实际误差，不能写成全视角精确标定。Face/Hair 的专用资产语义继续保留原来的独立实现边界。

运行时绑定只使用保存好的 Profile 与材质包，编辑器的临时 Profile 不进入角色持久化数据。真实验收图必须来自 UE 输出，UI 概念图不能作渲染证明。
