# Toon Light：明暗、曲线与角色区域

更新日期：2026-10-29。我们用这个页面调整角色的明暗分界、高光参考形状和着色模型，并把结果保存为可复用风格与运行时材质包。窗口延续既有 NPR 调制入口；Outline、Rim Light 和 Surface 仍按原职责工作。

## 当前实现与验证

**已实现并验证，范围限于下述环境与夹具**：2026-10-28 至 29，UE 5.8.3 / CL 58210709、Windows 11、RTX 4060 Laptop / DX12 SM6。Editor/Game 构建、Cook/Stage/Archive、13 项自动化、最后两项 UI 复测及独立打包 Game 的两项测试通过；23 张真实 HDR 捕获检查了响应和热更新。详细数值、原始数据、源码/资产哈希及未覆盖项见 [本轮验证](ValidationReport.md) 和 [Validation.json](Validation.json)。完整 S58 生产门禁仍未验收，概念 UI 图不作为实机或渲染证明。

## 参数、单位与兼容

| 统一参数 | 含义与默认值 | 硬域 / 推荐范围 | 依赖与后端边界 |
| --- | --- | --- | --- |
| `TerminatorDotCenter` | 明暗中心，默认 0；输入为有符号 N·L | [-1,1] / [-0.5,0.5] | S58 原生 Toon；负阈值仍受角色自影与外层光照调度限制 |
| `TerminatorDotHalfWidth` | 完整过渡宽度的一半，默认 0.05 | [0,0.5] / [0,0.25] | 0 有明确阶跃参考，实际 LUT 保留有限过滤；极小非零值超出后端精度时明确拒绝 |
| `SpecHalfAngleRad` | 高光降至半峰的半向量角度，默认 8°，数据存弧度 | [1°,60°] / [1°,25°] | 窗口显示度数；原生后端采用参考近似，尚非全视角标定 |
| `SpecEdgeSoftness` | 高光边缘柔度，默认 0.15 | [0,1] / [0,1] | 实际角域半宽随半峰角变化；0 使用显式硬边极限 |
| `SpecPeakScale` | 高光峰值线性倍率，默认 1 | 非负有限值 / [0,2] | 0 有效；原生 FP16 上限 65504，超出时拒绝转换，不缩小统一语义硬域 |

这五个 ID 沿用 `NPRParameterContract.v1.json`，没有改名或改默认值。风格按“契约默认 → Style Defaults → Generic 材质覆写 → 当前槽的稀疏覆写”解析。明确写入的 0 有效；每行 `↺` 删除当前槽的这一项覆写，恢复继承，不能用写入 0 代替 Reset。

着色模型是离散配置：**继承原模型、Default Lit、Substrate Toon**。它选择材质家族，并不是一个每帧随便写入的 MID 浮点数。旧风格新增字段默认 `Inherit`，不会因加载旧资产而改变场景。

“继承原模型”保留受支持源图的着色模型、专用输入和材质实例的模型覆写，例如已有 Subsurface；不会悄悄切为 Default Lit。原图不是直接 Toon BSDF 时，Toon 艺术值继续保存，但本后端不执行这些 Ramp 映射，材质包会记录限制。

过渡形状、暗/亮部响应 RGB、阴影合成和曲线生成开关属于版本化的风格资源选项，尚未新增全局语义 ID。RGB 是线性响应系数，还会乘原 BaseColor 和照明；它不是最终屏幕绝对颜色，Alpha 不参与计算。

## 明暗怎样计算

设 `q = N·L`，`τ` 是中心，`w` 是半宽。N 和 L 是单位向量，所以 q 的范围是 [-1,1]。

```text
z = Clamp((q - τ + w) / (2w), 0, 1)         当 w > 0
z = 0 / 0.5 / 1                            当 q < τ / q = τ / q > τ，且 w = 0
Linear(q) = z
Hermite(q) = z*z*(3 - 2*z)
响应 RGB = 暗部响应 + (亮部响应 - 暗部响应) * 过渡响应
```

例如中心 0.20、半宽 0.08，过渡从 q=0.12 开始，到 q=0.28 结束；q=0.20 时为两色的中间值。完整宽度是 0.16。

原生曲线使用 [0,1] 坐标，因此转换为 `u=(q+1)/2`、`t=(τ+1)/2`、`h=w/2`。生成器保留原函数的支持区间和导数：线性用少量转折键，Hermite 用明确的三次曲线与切线，通常每通道不超过 5 个键；不会把 Hermite 偷换成线性。

越界时先限制函数的可达域。例如 τ=0.95、w=0.2、暗亮系数为 0.1/1，q=1 的线性响应是 0.6625；不能把域外的亮平台压到边界并变成 1。

CPU 曲线与 GPU 纹理要分别理解。引擎默认把每条曲线在 `(i+0.5)/R` 处采样成 FP16，再双线性读取；R 默认 64。转折点和最外端会出现过滤差异。检查中分别记录理想函数、按源码规则计算的过滤参考和真实 HDR 读回。

## 高光怎样映射

参考模型使用半向量与法线的角度 θ，半峰角为 β：

```text
δ = 0.95 * SpecEdgeSoftness * min(β, π/2 - β)
参考高光 = SpecPeakScale * (1 - Hermite(θ; β, δ))
```

当 δ=0 时，θ 小于 β 取满值，大于 β 取 0，等于 β 取半值。S58 的原生 SpecularRamp 输入是 GGX 分布经能量查表后的值，因此 Adapter 以各向同性 roughness=0.5 的 `D(θ)/D(0)` 反算参考曲线。这个约定没有使用 `1-roughness`。

原生着色仍包含随观察方向变化的能量 LUT、原始 Specular/F0、NoL、可见度和灯型处理。矩形光、各向异性和复杂视角下不保证角域等价。我们在 UI 标出“原生后端近似”，并在材质包记录逐参数质量条件；不能把这个参考映射称为完整高光标定。

生成角域参考时使用独立的 `NPR_ToonReferenceRoughness=0.5`。原始粗糙度连接保存在派生图的专用转接节点中；关闭艺术高光生成或切回 Default Lit 时恢复原连接，原材质与其数值保持原样。

## 按顺序使用

1. 在关卡选择角色，打开 Toon 页面，点击“使用关卡选中角色”。
2. 在中央模型上点选区域，或在右侧选择 `LOD / Section → 材质槽`。同一槽的各行会同步选中。需要看清局部时点“隔离当前槽”；它只改变预览副本的可见性。
3. 选择着色模型。调节中心、半宽、响应颜色与高光，或点击“创建 / 刷新私有预览”。小曲线和放大窗口共享同一参数；曲线上拖动调整中心，按住 Shift 拖动调整半宽。
4. 需要引擎原始曲线、偏移纹理、排线、消光和间接光设置时展开“后端高级”。取消对应的“艺术参数生成”后再直接编辑原始 Ramp，避免下一次艺术参数更新重新生成这条曲线。阴影模式保持一个明确选择。
5. 点击“保存风格”，保存统一艺术参数和包含原始高级设置的后端预设。统一风格用于参数继承；“后端预设”选择器用于恢复完整原生设置，并继续保留当前目标的表面输入。
6. 点击“应用到所选槽”，生成独立不可变资源包并写入角色绑定。**保存关卡**后，角色配置才会在重开时保留。保存风格本身不会自动修改关卡材质。

选择其他区域会保留各槽尚未应用的草稿。撤销/重做恢复参数与稀疏覆写；普通热更新复用材质和 Profile。首次创建材质、切换着色模型或改变需要不同图结构的选项仍可能编译。

组合预览中的描边辅助网格也可能收到鼠标命中。我们沿其附着关系找到源网格副本，再解析 Section/材质槽；不必为选择区域关闭描边。普通左键用于选择，拖动超过 4 像素不切换；Alt、右键等相机操作保留。需要排查输入时，可仅在 Editor 启动参数中加 `-ToonPickTrace` 查看事件、命中与映射记录。

## 保存与运行时

后端包包含独立 ToonProfile、母材质和材质实例，并记录艺术值、模型选择及质量条件。现有资产不会被覆盖；编辑器临时 Profile 不写进角色持久化配置。`NPRStyleBindingComponent` 保存目标 Mesh 与 `ToonPackage`，注册时调用 `ApplyConfiguredToon`。

运行时只绑定已加载的资源，为每个槽创建各自 MID。先检查所有槽和参数，再更换材质；非法、缺失或重复槽会整体失败。恢复时仅恢复仍由本组件占有的材质，其他系统后续设置的材质会保留。运行时不修改 ToonProfile。

本轮打包 Game 实际读取保存的测试关卡，注册时恢复 MID，并验证切换到预制 Default Lit 包再切回 Toon 包。资源预加载和 PSO（图形管线状态）准备仍是独立工作：首次启动观察到了 PSO miss，不能把“没有新增 Shader 编译”解释成“首次切换绝无卡顿”。

Rim 使用同一个已生成表面时，`ApplyConfiguredRim` 继续更新四个 Rim 参数，不用旧 Rim 母材质覆盖 Toon。描边仍由原有独立组件和阶段执行。

## 支持范围与限制

当前转换支持 Opaque/Masked 的传统输入、Material Attributes、直接 Toon 和直接 Shading Models 根节点，保留原输入网络、材质实例参数、法线、遮罩、WPO 与自发光。任意分层 Substrate 根节点和透明材质会在换材质前给出诊断；不会假装完成任意原图转换。

局部编辑按材质槽生效，跨 LOD 的同槽区域一起变化。当前页面遇到已有组件同时管理多个槽时，要求更新完整后端包，避免只编辑一项却覆盖其他槽。Face/Hair 的专用明暗和发丝高光需要对应资产与独立实现，不能从 Generic 后端直接推出。
