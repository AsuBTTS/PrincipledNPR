## 冻结的架构原则

- 理论层保留signed-dot diffuse、angular specular、CriticalAzimuth Face与shift frame Hair；参数名/单位/契约不因后端变化偷偷改写。
- S58复用原生灯光遍历/衰减/多灯/阴影/Sky/Lumen与反射。MPC仅供Face艺术key/reference与诊断；不重建Generic/Hair所有灯光。
- `NPRStyleProfile→NPRBackendSubstrateToon→BackendStylePackage{ToonProfile,MIC,manifest,quality}`。Style存canonical语义，后端包存UE资源、patch/CL、Blendable配置、映射与误差。
- Exact区分数据/配置层和外观层；Approx带有效域/联动/标定证据；必需Unsupported拒绝生成生产包。
- Profile Settings按官方限制保持运行时不可变。Editor预生成Profile_A/B及共Master的MIC_A/B，预载后各自创建MID，SetMaterial切换角色bundle；普通graph scalar/vector/texture可动态更新。
- 未验证公开MID SetToonProfile，不编造setter；render-thread proxy setter不是游戏线程接口。Profile差异不默认导致复制Master或HLSL重编，但资源/PSO首次成本必须测。
- Rim/Color/Outline继续由独立层完成；Emissive艺术项不自动得到native visibility。

## Face与Hair的硬边界

Face公开节点没有逐灯Mask/NoLOverride/VisibilityOverride；完整Face逐灯替换仍Unsupported。本机源码确认PatternUV每轴12bit、offset先frac(UV*Size)、原纹理以Wrap烘焙到N−2 atlas内部区域；u=1会回到0，纹理Clamp无法修复，因此不得直接实现原identity全范围[-k,k]端点方案。使用远离接缝的内部单调区间，校准实际atlas函数h后离线逆映射`u=h⁻¹((Δ/k+1)/2)`，记录有效域、texel/量化/过滤误差；超范围限幅或拒绝，k=0禁用。`x_target(Dface)`仅在可达单调响应与有限右逆存在时定义；任意RGB/multiband不保证逆。key offset仍作用于所有native灯，不能称逐灯Exact。

Diffuse实际signed坐标为`(NoL+1)/2`；IncludeShadow off在Ramp后外乘透射，on先乘透射到坐标再加offset、Ramp后不外乘透射。Face优先测off分支；on中正offset可能抬亮完全遮挡区，必须回归。单灯零角方向光的terminator坐标`t=(τ+1)/2`、半宽`w/2`为坐标层Exact，native atlas默认64/最低64、采样和GI/外乘仍需画面标定。

Face BaseColor调制保留native lighting但可能双分界；Emissive差值会绕过visibility。桥接未过时，只为Face选择专用A+/C或明确研究A0，不为全角色退回受控灯光。严格Face生产合同不满足时不得宣称完整3Model V1完成。

Hair编译入口已有缺口证据：CL58210709 legacy basis只注册Normal，MIR Build basis切线为nullptr且不传Tangent/Anisotropy。记录实际translator后再测0/45/90°Flow，不能凭pin存在解除Gate。非Rect SpecularRamp输入为GGX D×NoV查表K，再saturate；该直接分支Vis/Fresnel被注释，外部仍乘NoL/SurfaceShadow，Rect另用LTC。无shift等值线在固定条件可研究逆映射，全视角Exact未确认。独立shift反例不变：仅倾T若正交化则shift消失，倾N/T则改变diffuse/GI；完整合同需专用入口/扩展或明示不支持。

## 缺陷与验收

历史Toon Tangent不完整与CSM/VSM差异已有Epic说明；本机Tangent/MIR入口缺口已确认，渲染方向和阴影修复回归仍未执行。commit `eef3f0de5c050521fd19362c6089abddcbc59445`不是数字CL。UE-388460官方tracker在专项复核时为Unresolved/Affects5.8/TargetFix6.0：DDC命中可能丢失Toon编译宏。使用隔离测试缓存，不删用户全局DDC；冷缓存一次成功不能关闭此任务。

灭绝系数0对应零吸收，不能误当不透射基线。先从目标实现/实验标定opaque shadow基线，再单独扫extinction。IncludeShadow开关须用假色ramp隔离坐标变化，不能只看变暗。

执行结果只能✓可用、△明确限制、✗不可用；执行前保持NotRun、verdict=null。实测与设计阈值分别存储。原数学验证16/16是Python双精度标量证据，未覆盖HLSL/fwidth/TSR/VSM/GPU或真实资产；第4–6节在专项修订中原样保留。
