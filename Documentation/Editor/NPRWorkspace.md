# NPR 调制：统一效果工作区

更新日期：2026-10-26。我们从同一个入口选择角色、查看各个 Mesh 已应用的效果，再进入对应效果调参。Mesh 是角色的网格组件；材质槽是这个组件上使用一份材质的位置。

状态：已实现并验证，限于本页记录的编译、受控自动化与真实 GPU 捕获；不同角色资产仍需单独检查。

## 1. 先看角色，再选择效果

工具栏和 **窗口 → NPR 调制** 打开角色效果总览。窗口最上方只保留 **NPR 调制**、**Outline**、**Rim Light** 三个导航按钮；NPR 调制用 16 号字，Outline 和 Rim Light 用较小的 12 号字。三个按钮的内容高度一致，文字垂直居中对齐；**NPR 调制** 本身是可点击的总入口。进入总览后，在页面内容中的分类区域按执行方式选择效果：

- **非后处理**：Rim Light、反向壳几何描边和 Surface 表面组合。
- **后处理**：Screen 屏幕空间描边。
- **Outline · 描边编辑**：保留原有的整角色、单槽、预设与高级参数编辑。分类中的描边入口先隔离查看已有结果；进入描边编辑器后才按需要修改方法。

总览按 Mesh 和材质槽列出实际登记的绑定，可以直接跳转对应的 Rim 或描边编辑器；Rim 跳转会定位到该 Mesh 的该槽。切换顶部页面不会清空同一角色尚未保存的 Rim 编辑。Rim 强度为 0 时仍会列出这份绑定，并显示强度 0；这不表示亮边正在发光。没有登记的第三方材质功能显示为未登记，不推断它已经被转换或支持独立开关。

## 2. 完整角色、隔离与原材质对比

选择关卡角色后点“使用关卡选中角色”。右侧显示真实网格和当前材质的预览副本；骨骼网格采用参考姿势。

每行可以“隔离 Mesh”或“隔离材质槽”。“只看 RimLight / HullOutline / ScreenOutline / Surface”进一步选择单项效果；“查看全部效果组合”恢复组合画面，“显示全部材质”恢复完整角色。所有隔离均只作用于临时预览副本，不修改源网格、关卡可见性、关卡材质参数或已有描边配置。

“原材质对比”打开第二个视口。两侧使用共享相机、相同模型和灯光；左侧读取本插件绑定前记录的材质，右侧显示当前效果。Studio、Warm、Raking 只改变预览灯光。“聚焦当前角色”按预览范围重新构图。

单效果过滤继续复用现有材质和描边控制器：Rim 使用预览 MID 副本，关闭预览中的第二份附加贡献；Surface 预览关闭 Rim 和描边；两种描边分别过滤预览区域的实际描边方法，并保留基础表面。这里没有新增 Shader Pass，也不改写关卡中的效果开关。

MID 是运行时材质实例，可以理解为当前槽使用的一份可调材质。我们先把有效编辑值写入这个槽的生产 MID，再把参数变化同步到相应的预览副本。预览缓存按“Mesh＋槽位”分别保存，只在源参数变化时同步，避免每帧清空参数或让两个槽串用同一份颜色。原材质对比读取绑定前保留的材质；如果其他系统已经替换这个槽，我们保留外部修改。

| 效果 | 实际执行位置 | 隔离时怎样查看 |
| --- | --- | --- |
| Rim Light | `MF_RimLight` 输出颜色贡献，经 Surface 母材质加入自发光 | 显示选定槽的当前 Rim 参数，移除预览中的独立第二份附加贡献 |
| Surface | Surface 母材质的基础颜色、法线、自发光输入 | 预览中关闭 Rim 与描边，查看已显式提供的基础表面 |
| 反向壳描边 | Outline 控制器建立并绘制外扩网格 | 仅保留反向壳区域方法，保留基础表面 |
| 屏幕空间描边 | Outline 控制器登记的屏幕后处理 | 仅保留屏幕空间区域方法，保留基础表面 |

“只看 Rim”用于检查当前表面上的亮边贡献，画面仍保留基础表面；它不是一张仅含发光像素的黑底贴图。Rim 算法、正面门控和抗锯齿公式见 [Rim Light 介绍](../rim_light_introduction.md)，Outline 的厘米/像素宽度与继承规则见 [Outline 介绍](../outline_introduction.md)。

## 3. Rim 的四项控制

窗口沿用既有参数，没有新增全局 Rim。宽度和柔和度在 UI 中用度数显示，Profile 与程序结构用弧度保存；写入材质时只转换一次。

| 控制 | 语义 ID | 默认值 | 硬范围 / 建议先尝试 | 可见变化 |
| --- | --- | --- | --- | --- |
| 亮边宽度 | `RimGrazingAngleRad` | 8° | 0°–90° / 1°–35° | 增大后更多侧向表面进入亮边 |
| 边缘柔和度 | `RimEdgeHalfWidthRad` | 2° | 0°–90° / 0°–10° | 增大后边界更缓；它是角度过渡的半宽 |
| 边缘光强度 | `RimPeakScale` | 0 | 有限非负 / 0–2 | 增大附加颜色贡献；0 是有效关闭值 |
| 边缘光颜色 | `RimColor` | 线性 RGB 白色 | 每通道有限非负 / 0–1 | 改变亮边颜色；黑色有效，Alpha 不参与计算 |

四项控制作用于当前选择的 Mesh/材质槽。Profile 是可复用的风格资产；Recipe 是已经声明材质能力的组合说明；Material Kind 是这份 Profile 中区分材质类型的键。它们不是全局、角色、组件逐级继承的 Rim 开关。相同 Profile 与 Material Kind 可以被多个绑定引用，保存共享 Profile 后，其他引用者下次解析也会得到这些值。需要独立风格时使用独立 Profile 或明确区分材质类型。

## 4. Rim Light 的操作顺序

1. 点击顶部 **Rim Light**，或进入 **NPR 调制** 总览，在 **非后处理 → Rim Light** 打开编辑页，再读取角色。此时即使还没有 Rim 绑定，也能查看角色、Mesh 和材质槽。
2. Mesh 列表沿用 Outline 的卡片形式：每个槽显示槽名、原材质名、支持情况，以及“Rim”“隔离”“编辑参数”“重置参数”。参数在当前卡片内展开；这是一份槽位配置，不是全局 Rim。已有保存绑定会载入自己的 Profile、Recipe 和源输入；新槽必须明确配置自己的源表面输入。
3. 选择或新建 Style Profile，选择包含 Rim 的兼容 Surface Recipe，加载 Profile。源输入仍由使用者明确提供，不自动迁移任意原材质图。
4. 配置齐全后勾选本槽“Rim”，或点击“应用 / Apply Preview”。此后拖动强度、调整颜色时，右侧角色实时更新；已加载的有效槽无需先重复点击应用。配置缺失会显示具体提示，不能只改控件而没有反馈。勾选“只看当前 Rim 效果”可以排除预览中的其他效果，取消后查看已应用效果组合。
5. “Rim”勾选与本槽非零强度对应，关闭时写入有效的 0；再次启用恢复这个槽上次的非零强度。“重置参数”将当前槽恢复为所选 Profile 的默认参数；未选择 Profile 时使用 8°、2°、0、白色。保存时删除对应的材质类型覆盖项。这里没有全局或角色级 Rim 继承链，因此不使用 Outline 的“恢复继承”名称；显式 0 和黑色仍是有效值。
6. 点击“保存风格与角色绑定”。各 Mesh/槽位使用各自的绑定组件；切换到另一个槽不会改写前一个槽已保存的配置。新槽的源输入不从上一个槽静默复制。

第一次配置时，展开“当前槽配置”，选择例如 `SR_DefaultLit_Rim` 这样的兼容 Recipe。在 `Source Surface` 中确认 `bConfigured`，填写原表面的基础颜色/贴图、法线/强度、自发光/贴图/倍率。这个操作将当前槽换成预制 Surface MID；它不会分析并复制任意第三方材质图。对复杂角色先在场景副本中尝试，并确认原有表面逻辑适合这份 Recipe。

观察亮边可以先用宽度 25°、柔和度 4°、强度 1、非黑色 RGB；这只是便于看变化的操作例子，不会改掉 8°、2°、0、白色的默认值。先改红色，再改绿色，确认当前槽的边缘变化；最后把强度归零，确认亮边消失。调整亮边不应改变未选中槽的预览参数。

宽度和柔和度在窗口里用度数显示，Profile 内用弧度保存，材质写入时只做一次单位转换。调参和 Undo 继续更新当前生产 MID；原材质对比与单效果过滤使用独立预览实例。预览实例按 Mesh 和材质槽分别缓存，只在源参数变化时同步，避免每帧清空并重建材质资源，也避免同一 Mesh 的不同槽共用一份参数。

Undo / Redo 同时恢复显示值与稀疏覆盖状态。外部系统换掉材质后，自动刷新、预览失败清理及角色切换均保留外部材质；需要明确覆盖时再点击应用预览。保存到磁盘后的 Undo 仍需要再次保存。

## 5. 没有看到变化时

| 现象 | 我们先检查什么 |
| --- | --- |
| 角色不在画面中 | 关卡是否只选择一个角色、是否读取选择；点“聚焦当前角色”，检查隔离目标 |
| 颜色或强度变了，亮边仍不可见 | 顶部状态是否提示缺少 Profile、Recipe 或源输入；强度是否为 0、颜色是否为黑；Shader 是否完成编译 |
| 改了别的槽却在观察旧位置 | 当前卡片、当前槽配置和隔离目标是否相同；取消隔离再核对整个角色 |
| 关闭本槽 Rim 后仍有发光 | 原材质自发光或其他附加贡献可能仍存在；用原材质对比和单效果过滤分别确认 |
| 应用后原有表面变了 | Recipe 不会自动迁移原材质图；核对显式输入，必要时恢复原材质并保留原表面逻辑 |
| 透明/裁切槽不能勾选 Rim | 当前预制 Rim 表面未适配这些 Blend Mode；列表允许查看和隔离，不代表可以自动转换 |

## 6. 范围、源码与验证

主要入口为 `NPROutlineEditorUI.cpp` 的工作区和共享视口、`NPRRimEditorUI.cpp` 的 Rim 编辑器，以及 `NPRModulationEditorLibrary` 的只读效果清单。旧的 `NPROutlineEditorLibrary::OpenEditor` 和 Outline 导出接口继续打开旧描边编辑路径；新的 `OpenWorkspace` 打开总览。

| 源码入口（相对于 `Plugins/PrincipledNPR/Source/`） | 负责什么 |
| --- | --- |
| `NPREditor/Private/NPROutlineEditorUI.cpp` | 顶部导航、总览分类、共享相机与预览副本 |
| `NPREditor/Private/NPRCharacterPreview.h` | 角色预览、隔离、过滤与导出接口 |
| `NPREditor/Private/NPRRimEditorUI.cpp` | 槽位卡片、交互更新、重置、Undo 与保存 |
| `NPREditor/Public/NPRModulationEditorLibrary.h` | 总览、编辑跳转和实际绑定清单的脚本入口 |
| `NPRRuntime/Private/NPRStyleBindingComponent.cpp` | 同槽 MID 调参与材质所有权检查 |
| `NPREditor/Private/Tests/NPRRimPreviewRenderTests.cpp` | 预览 MID 的多槽读回与真实 GPU 颜色/强度回归 |

2026-10-26，UE 5.8.3 / CL58210709、Windows 11、DX12 SM6：Editor/Game 构建及 10 项 Rim、Surface、编辑器自动化通过。新增预览材质测试导出 5 张真实 GPU 图像：红/绿色变化、强度提高、归零均通过，归零与初始画面的最大像素差为 0；多槽预览实例、Undo、外部材质保护和隔离均有独立用例。GPU 捕获直接使用共享预览返回的 MID，在独立球体场景中渲染，不冒充编辑器窗口截图。
