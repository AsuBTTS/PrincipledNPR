# 多粒度 Outline 使用说明

当前按钮位置、基础宽度与局部覆写的带标注实机截图，见 [整角色图文操作流程](../操作流程.md)。

代码所在项目：`E:\unrealProjects\PrincipledNPR`。打开其他副本需要同步代码和材质后重新构建。

1. 选中关卡中的角色 Actor，打开“窗口 → Principled NPR · Outline”。点击“创建 / 打开角色级配置”。首次创建会收集该 Actor 的普通 SkeletalMeshComponent 和 StaticMeshComponent，排除瞬态辅助组件与 InstancedStaticMesh；没有合并网格。
2. 在同一 Details 区域设置 `Base Settings`。`Method` 选择算法，`Scope` 选择范围。统一外轮廓必须 Screen Space；独立区域可使用 Hull、Screen Space 或 None。
3. `Meshes` 每项对应源组件。`Override` 仅勾选的字段覆盖父级，`Values` 提供覆盖值。Material 规则按稳定的 `Material Slot Name` 查找，不按材质对象是否相同分组。
4. 覆盖顺序为 Actor → Component → Material → Section。Material 字段继承 Component；Section 字段继承 Material。`Override Enabled` 可局部关闭；Actor 总开关关闭时局部不能重新开启。`Method=None` 同样关闭区域。
5. Section 填写真实 LOD / Section 索引。蓝图或 Python `GetSectionMapping` 可查询。当前仅接受单 LOD、独占材质槽的 Section；共享槽和多 LOD Section 覆盖报错。多个 Section 共用槽时，Material 规则共同生效。
6. Unified 使用一个 Stencil、一次后处理，启用区域必须共享基础风格；颜色、宽度等局部差异应选 Independent Regions。局部关闭可用于统一组。
7. `Use Vertex Color Width` 仅用于 Hull，将资产顶点颜色 R 乘到壳宽度，0 关闭、1 全宽。它不会导入/烘焙平滑描边法线。组件 Mesh Paint 颜色覆盖、布料、原材质 WPO、Morph/Deformer 需要单独验证或适配。
8. 角色模式的双视口会加载整组 Static / Skeletal 组件，左侧保留原表面，右侧应用角色描边，共享相机与灯光，也可导出 PNG。组件相对变换、材质与隐藏分区会同步；骨骼预览为参考姿势，运行时动画仍在关卡中验证。点击“保存基础预设与当前关卡”，保存基础风格和关卡规则，重开关卡恢复辅助网格。

`MultiScope_CharacterGroup` 是两个球体组成的渲染测试组。查看人物应选 `MultiScope_Skeletal`（两个互补骨骼组件，灰色验证表面），或 `Outline_TexturedCharacter`（保留角色纹理的展示对象）。角色级预览现在会实际加载组件，不再显示空白双视口。

已有单槽绑定和角色级组件不能同时开启。将旧绑定 `Method=None` 后创建角色配置；返回旧路径时关闭角色组件 `Enabled`。原材质恢复、旧预设、单槽转换和 PNG 对比入口保留。

Preset 只保存风格快照；组件引用、覆盖规则和 Scope 保存到关卡。应用预设更新 Actor 基础值，已勾选的局部覆盖继续有效。修改预设资产不会自动改变已应用角色。

只接受 Opaque 覆盖。Masked、Translucent、Nanite、实例化网格及源 CustomDepth 冲突有门禁。Stencil 扫描分配并非跨插件集中协议，后加入的外部系统仍可能冲突。

辅助网格数量随区域风格增加；独立 Screen 风格各增加一次全屏处理，改参数会重建辅助组。大量区域/角色需要性能分析与缓存优化后确定预算。
