# Outline 单材质槽操作流程

整角色模式请先阅读 [整角色操作指南](../NPR调制插件使用说明.md)。本页保留单槽流程的补充说明。

整角色截图对应的按钮说明、整角色与单槽模式的区别，见 [当前窗口说明](../NPR调制插件使用说明.md)。整角色使用“创建 / 打开角色级配置”和 `Meshes` 区域规则，不经过单槽转换按钮。

本工具用于一个受控骨骼角色的一个 **Opaque 材质槽**。转换创建原材质的子材质实例，继承原表面着色、贴图和静态参数，并用独立描边组件叠加 Outline；它不把整个 PBR 表面改成 Toon。

## 1. 选择角色与材质槽

1. 打开关卡 `/Game/NPR/Maps/L_Outline_Workflow`。
2. 在大纲中选中 `Outline_ControlledCharacter_Slot02`。
3. 选择菜单 **窗口 → NPR 调制**。
4. 点击 **使用关卡选中角色 / Use Selection**。
5. 第一次使用选择 **2 号材质槽**；这是受控的衣物 PBR 槽。已有绑定时工具会优先选中已绑定槽。

也可对其他只有一个主 SkeletalMeshComponent 的 Actor 使用工具。源材质必须是已保存的 Opaque 表面材质；Masked 和 Translucent 不会被静默当作 Opaque 转换。

## 2. 转换并绑定

点击 **转换 / 更新单槽 Outline 绑定**。

- 生成的 MIC 保存在 `/Game/NPR/Outline/Generated`。
- 原材质保留为 MIC 的父级，组件单独保留原材质引用。
- 只替换选中的源材质槽；其他源槽位保持原绑定。
- 重复转换同一个已绑定槽会复用绑定，不重复创建材质实例。

## 3. 调整描边

在参数 Details 面板中调整：

| 参数 | 用途 |
|---|---|
| 描边方式 / Method | 关闭、反向壳、屏幕空间 |
| 描边颜色 / Color | 描边 RGB 颜色 |
| 壳扩张宽度 / Width (cm) | 反向壳的世界空间扩张距离，0–5 cm |
| 屏幕宽度 / Width (px) | 屏幕空间的采样扩张距离，0–8 输出像素 |
| 深度容差 / Depth Bias (cm) | 屏幕空间遮挡判断的容差，位于高级参数 |

右侧 NPR 预览会跟随工作参数刷新；属性编辑结束后参数写入场景绑定。两个宽度字段具有不同单位，切换方法不会把厘米误解释为像素。两种描边的颜色都进入场景曝光和色调映射；屏幕空间描边在 DOF 后、TSR/TAA 前合成。颜色数值是线性颜色，最终显示会随曝光和色调映射变化；旧版色调映射后合成的颜色响应已调整。

宽度现在按“基础 × 边类型倍率 × 区域倍率”合成，Hull 还可用资产顶点色与 UV0 Mask 细化。默认基础值已收细为 1.25 px / 0.1 cm。边缘来源支持范围、区域覆写步骤和继承规则见 [多层宽度控制](多层宽度控制.md)。

屏幕空间依赖项目的 **Custom Depth-Stencil Pass = Enabled with Stencil**，本项目配置为 `r.CustomDepth=3`，配置变化后需重启。它使用独立辅助网格，并分配空闲 Stencil ID。若源网格本身已经写入 Custom Depth，工具会给出诊断，要求先明确源 Stencil 的所有权；不会覆盖源网格的 Stencil 设置。

## 4. 对比与灯光

- 左视口显示保留的原材质，右视口显示继承同一表面并叠加 Outline 的结果。
- 两个视口共享相机状态，几何、材质和灯光条件一致。
- 点击 **聚焦当前角色 / Focus**，使用编辑器视口导航调整观察角度。
- **标准 / 暖光 / 侧光** 按钮同时改变两边的灯光。
- **导出双视口 PNG** 输出到 `Saved/NPR/Outline/Previews/<时间戳>/Original.png` 和 `Outline.png`，成功后可点击 **打开上次导出目录**。

预览使用角色参考姿态。实际关卡中的辅助网格通过 Leader Pose 跟随目标骨骼网格。原材质对比保留的是引用，父材质后来被编辑时，其变化也会反映到子实例。

## 5. 保存与应用预设

1. 输入预设包路径，例如 `/Game/NPR/Outline/Presets/OP_MyOutline`。
2. 点击 **保存基础预设与当前关卡**。
3. 预设保存颜色、两类宽度和描边方式；场景保存角色、槽位、原材质、转换实例与该次应用参数。
4. 在 **选择并应用基础风格预设** 资产选择器中选取预设，可应用到当前已转换槽位。重复应用同一资产请点击 **重新应用所选预设**。

预设按值应用，修改一处绑定不会隐式修改其他角色或已保存预设。输入已有同类预设路径并保存会更新该预设；其他资产类型的同名路径会被拒绝。

## 6. 保存后重开

1. 正常关闭编辑器。
2. 重新打开项目和 `L_Outline_Workflow`。
3. 选中原角色，再打开 Outline 窗口并点击 Use Selection。
4. 工具从场景组件恢复原材质、转换实例、槽位、颜色、宽度、方式和预设引用。

**重新读取当前角色绑定** 只重新读取窗口当前角色在场景内存中的绑定；不依赖此时关卡另选了谁。真实的磁盘持久化验证需要上述关闭、重开步骤。

## 恢复原材质

点击 **恢复单槽原材质并移除绑定**。只有目标槽仍由该转换实例占用时才恢复；若其他系统已更换该槽，工具会拒绝覆盖并显示原因。转换、属性提交和恢复操作使用编辑器事务。生成资产保留在内容浏览器中供检查或复用。

整角色模式下对应按钮是 **关闭角色描边（保留配置） / 启用角色描边**，切换启用状态，不修改源材质。

日常使用无需执行 Python 脚本。`Tools/create_outline_backend_assets.py` 和 `create_outline_workflow_fixture.py` 是资产重建工具，`verify_outline_workflow.py` 是开发验证入口。
