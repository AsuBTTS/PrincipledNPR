# Outline 窗口按钮说明与修复

按钮位置与步骤对应的实机截图、编号标注，见 [图文操作流程](操作流程.md)。

## 当前截图对应的模式

标题为“角色与区域”、目标显示 `Actor Outline`，表示正在编辑整角色配置。该模式从 Actor 的 `Meshes` 数组管理组件、Material Slot 和 Section；源材质不替换。

左上原有材质槽下拉框和“转换并绑定 Outline 实例”属于单槽流程，在整角色模式下不适用。本次改为自动隐藏，避免与 `Meshes → Materials` 混淆。

## 按钮和控件的作用

| 按钮或控件 | 实际作用 | 看起来没有变化的常见原因 / 修复后的提示 |
|---|---|---|
| 使用关卡选中角色 | 从关卡大纲读取唯一选中的 Actor，切换当前编辑目标 | 点击右侧预览不改变关卡选择。没有唯一选择时明确报错，保留当前编辑目标 |
| 创建 / 打开角色级配置 | 为关卡当前选中的 Actor 创建或打开角色配置 | 已有配置时直接打开；现在会显示角色名、组件数和渲染错误 |
| 重新收集角色组件 | 重扫当前角色的持久网格组件，保留已有组件的区域规则 | 网格没有增减时画面应当不变；现在报告总数、新增数、移除数 |
| Enabled | 开关整角色描边 | 关闭后配置保留；右侧源表面仍然显示 |
| Scope | 选择统一外轮廓或独立区域组织方式 | 统一外轮廓要求同组宽度一致；区域差异需切换独立区域 |
| Base Settings / Meshes 左侧三角 | 展开或折叠属性 | 展开本身不改参数。局部参数要勾选对应 Override 才参与最终结果 |
| 已应用预设（只读引用） | 显示最近应用的预设来源 | 不是应用开关，也不会自动回写资产；使用下方预设选择器或“重新应用” |
| 聚焦当前角色 | 将两个相机同步到当前角色的正面全身构图 | 已经处于同一构图时重复点击画面可不变；现在有完成提示，并立即同步两个视口客户端 |
| 标准 / 暖光 / 侧光 | 同时切换两个预览场景的灯光 | 不修改关卡灯光、风格参数或材质。重复选相同灯光时画面可不变 |
| 选择并应用基础风格预设 | 选择新预设后立即把基础参数应用到当前目标 | 区域覆写仍保留；参数相同或被局部规则覆盖时结果可能相同。失败会显示原因 |
| 重新应用所选预设 | 在选择不变时，再次应用预设资产当前参数 | 解决同一资产选择不触发变更事件的问题；不从磁盘重载资产 |
| 预设保存路径 | 指定基础预设资产的包路径 | 编辑路径不保存也不应用；同名 Outline 预设会在保存时更新 |
| 保存基础预设与当前关卡 | 保存基础风格资产，并保存当前角色所在关卡 | 区域规则保存在关卡组件中，不被打包为通用风格预设；失败区分预设保存和关卡保存阶段 |
| 重新读取当前角色绑定 | 重读窗口当前目标的内存配置并重建预览 | 不从磁盘重开关卡，不依赖此刻大纲另选了谁；配置不变时画面可相同 |
| 导出双视口 PNG | 保存当前双视口帧 | 每次写入独立时间目录，避免覆盖；提示完整目录 |
| 打开上次导出目录 | 在文件资源管理器中打开最近一次导出目录 | 仅导出成功后显示 |
| 关闭角色描边（保留配置） / 启用角色描边 | 切换角色配置的启用状态 | 修复旧按钮在 Actor 模式下直接返回的问题；保留配置，可随时重新启用 |
| 材质槽选择 / 转换更新单槽绑定 | 单槽模式下选择一个骨骼网格材质槽，创建或更新继承原材质的 MIC 及绑定 | 整角色模式隐藏。单槽模式缺少有效网格或槽位时禁用 |
| 恢复单槽原材质并移除绑定 | 单槽模式恢复记录的原材质并移除绑定组件 | 如果其他系统已修改源槽，拒绝覆盖并保留界面目标、显示原因 |

资产行的回箭头和文件夹图标是 UE 的“使用内容浏览器选择”和“定位资产”等标准操作；只读引用不支持写入。属性右侧的回转箭头用于恢复该属性默认值，数组 `+` / 清空图标用于编辑配置列表，不是应用/保存按钮。

## 已定位并修复的原因

1. 旧恢复按钮仅处理单槽 `Binding`；角色模式的 `Group` 有效但 `Binding` 为空，导致点击后静默返回。现在按模式分别处理：整角色可关闭/启用，单槽可恢复材质。
2. 预设选择器仅依赖 `OnObjectChanged`；选回同一个资产不一定产生事件。新增显式重新应用按钮。
3. Actor 预设加载忽略失败返回值，可能显示错误的已加载资产。现在通过共享编辑器服务检查结果，失败保留已应用状态并显示具体原因。
4. 操作提示位于滚动区域底部，容易不可见，且可能被重新加载或渲染错误覆盖。现在左栏顶部固定显示最后一次操作结果，另有短时通知；渲染错误独立展示。
5. 创建配置读取缓存选择，重新读取绑定又依赖即时关卡选择，两者语义混乱。现在创建/打开读取关卡选择；重新读取固定作用于窗口当前目标。
6. Focus 修改共享相机后没有立即更新两个客户端，旧相机状态可能在下一 Tick 写回。现在立即同步两个客户端。
7. 导出按钮缺少目标校验、成功位置提示且反复覆盖文件。现在无有效预览时禁用，每次创建独立目录并提供打开目录入口。

描边的细线默认值保持为 Screen 1.25 px / Hull 0.1 cm；本次不修改渲染材质或时序抗锯齿设置。
