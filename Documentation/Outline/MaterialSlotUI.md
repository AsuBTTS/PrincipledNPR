# 材质槽界面改进与验证记录

2026-10-20，UE 5.8.3 / CL 58210709，Windows。


我们在角色配置的 `Meshes` 中直接读取真实使用中的材质槽，显示编号、槽名、当前材质和 Opaque 支持状态。展开组件后，取消某行的“描边”即可排除这一槽；不再添加空规则或输入槽名。勾选会创建或更新本槽启用覆写，“恢复继承”删除本槽规则并恢复继承。Actor 总开关和更深层 Section 规则仍然生效。

勾选“隔离”可只看该组件的当前材质槽，选中时显示“隔离中”；取消勾选或点击工具栏“显示全部材质”恢复全角色。切换到另一槽时，原槽的隔离勾选会同步取消。隔离只作用于临时预览，不改变关卡组件可见性、原始材质或源网格。隔离预览会让其他区域不参与临时描边，所以它不能代替完整角色验收。Masked / Translucent 槽仍无法生成正确描边覆盖，但可以单独查看原表面、取消该槽描边。

工具栏“原材质对比”默认关闭，开启后恢复原材质与 Outline 双视口；相机和灯光继续共享。PNG 导出仍输出 Original.png 和 Outline.png，隔离状态会体现在导出画面中。

组件源引用改为名称提示，避免展开整套 UE 网格组件属性。组件级覆写与 Section 高级覆写分别通过“组件参数”和“Section 高级”按需展开；材质槽“编辑参数”只展开当前槽，展开后显示“收起参数”。按钮使用明显背景、加粗文字与增大的点击区域。已有 None、未使用或重复槽名规则会显示清理按钮；点击后移除无效项，同名规则保留第一条，因此清理前应确认不需要后续重复条目的参数。


状态：已实现并验证（仅下列界面与预览操作范围）。没有更改运行时参数声明、预设结构、材质资产或 Shader 算法。

源码：NPROutlineMeshCustomization.h；NPROutlineEditorUI.cpp。

2026-10-20：顶级入口改为“窗口 → NPR 调制”，窗口内切换 Outline 和 Rim Light 占位页。材质槽改用原生 Slate 分组卡片；名称、材质与覆盖能力分行显示，描边/隔离使用勾选框，“参数”按需展开，“恢复继承”删除本槽覆写。隔离状态直接读取当前预览目标，避免按钮文字与画面状态不一致。编辑属性只更新窗口内反馈，同一提示去重。

界面状态与角色规则分开：已有规则的参数展开/收起只改变窗口；第一次打开尚无规则的槽会建立一条使用继承值的局部规则，修改字段仍须勾选对应覆写。“恢复继承”删除该槽规则。窄窗口的预览工具栏自动换行，左侧编辑区提供最小宽度。

## 本次实际验证范围

我们使用 Windows 上的 UE 5.8.3 / CL 58210709，打开 `L_TwoStyle_CharacterProbe` 中的 `PNPR_ChenQianyu_EndfieldLike`：

- Editor Development 编译通过，重新打开同一项目，旧 OpenEditor 脚本入口进入 NPR 调制的 Outline 页。
- Outline / Rim Light 占位页切换与返回正常；边缘光没有渲染实现。
- 本槽“编辑参数 / 收起参数”文字与展开状态对应，按钮采用 UE 主按钮背景与加粗文字；展开已有规则未修改角色数据。组件与 Section 高级配置没有一并展开。
- 槽 0 切到槽 2 时，仅当前槽保留“隔离中”勾选；取消后恢复整角色。隔离时卡片背景同步变化。
- 原材质对比可开关；850 × 600 窗口的预览工具栏换行，常用控件仍可访问。
- 隔离开关前后读回源组件可见性、材质引用、相对位置及 Actor / Component / Material / Section 规则，均与基线一致。双视口 PNG 导出成功，保留真实导出图及读回 JSON。

`MaterialSlotUI/Validation.json` 记录环境与边界，`MaterialSlotUI/Readbacks.json` 保留本次读回数据。`IsolatedCloth.png` 和 `FullCharacter.png` 来自实际 UE 预览导出，未生成或修改图像；采集时使用当前关卡已有的粉色描边参数，图片不代表默认风格。它们在最终按钮背景强调前采集，渲染与隔离代码相同。

本次没有重跑 67 项时间稳定性门禁；没有验证动画、多 LOD、静态网格、无效规则清理、恢复继承和全套新建配置流程。Masked / Translucent 适配仍未实现；Rim Light 仍为占位。本记录不能作为这些功能的验收。
