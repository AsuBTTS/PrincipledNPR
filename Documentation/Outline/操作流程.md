# Outline 操作流程：整角色图文指南

旧版截图保留作历史操作证据；2026-10-20 的材质槽列表与隔离操作见 [材质槽界面改进](MaterialSlotUI.md)。

本页对应当前“角色与区域 / Actor Outline”窗口。截图来自项目实际 UE 界面，橙色框与编号是文档标注；每张图都附未标注原图，可放大对照。

示例关卡：`/Game/NPR/Maps/L_Outline_MultiScope_v1`；示例角色：`Outline_TexturedCharacter`。日常使用不需要运行 Python 脚本。

如果要操作一个骨骼网格的单个材质槽，请阅读 [单材质槽操作流程](单材质槽操作流程.md)。整角色通过 `Meshes` 管理局部区域。

## 1. 读取角色，打开配置

1. 在关卡大纲中只选中一个角色 Actor。
2. 打开 **窗口 → NPR 调制 → Outline · 描边**。
3. 点击 **使用关卡选中角色 / Use Selection**。点击右侧预览不等同于选中关卡角色。
4. 首次使用点击 **创建 / 打开角色级配置**；已有配置时会打开原配置。
5. 确认目标角色名称，并检查顶部操作结果。

![角色读取、基础设置、Meshes、双视口与保存区域](Guide/01-overview.png)

[查看未标注原图](Guide/Raw/01-overview.jpg)

图中 **①** 是角色读取入口，**②** 是启用状态与基础设置，**③** 是局部区域入口，**④** 是左右对比视口，**⑤** 是预设与保存区域。

整角色模式直接管理源组件，不需要转换单槽；该模式下单槽选择器和转换按钮会隐藏。

## 2. 调整基础宽度

展开 **Base Settings**，可点击展开箭头或双击属性组标题。

![基础宽度、边类型倍率、区域倍率和灰色入口说明](Guide/02-width.png)

[查看完整原始截图](Guide/Raw/02-width.jpg)

| 图中编号 | 内容 | 使用方式 |
|---|---|---|
| ① | Method 与基础宽度 | Screen Space 使用像素宽度；Hull 使用厘米宽度。截图为 Screen **1.25 px**，Hull 默认 **0.1 cm** |
| ② | Edge Source 与边类型倍率 | Silhouette 对应轮廓倍率；手工材质边界使用 Feature Boundary，并要求 Screen + Independent Regions |
| ③ | Local Scale | 区域宽度倍率；1 表示保持宽度，0.8 表示乘以 0.8 |
| ④ | Vertex Color / UV Mask | Screen 下灰色是能力限制；连续顶点色与 UV Mask 宽度控制用于 Hull |

```text
区域宽度 = 基础宽度 × 当前边类型倍率 × 区域倍率
```

例如 `1.25 px × 1 × 0.8 = 1 px`。这里是采样扩张距离，最终可见线厚还受轮廓方向和抗锯齿影响；建议从细线默认值开始调整。

**Scope 决定区域组织方式：**

- **统一外轮廓 / Unified Silhouette**：使用 Screen Space；同组需要统一样式与宽度，允许局部关闭。
- **独立区域 / Independent Regions**：需要不同局部宽度、颜色或手工区域边界时选择。

当前没有独立的 crease / occlusion 边检测；Depth Bias 用于遮挡容差。完整限制见 [多层宽度控制](多层宽度控制.md)。

## 3. 设置局部区域覆写

**要让不同区域使用不同宽度，请先把 Scope 切到 Independent Regions。** 下图只展示入口，保留演示角色原配置，没有为拍图勾选新覆写或修改宽度。

![源组件、区域宽度覆写开关、Values 与材质槽入口](Guide/03-regions.png)

[查看完整原始截图](Guide/Raw/03-regions.jpg)

1. 按图 **①** 展开 `Meshes → 索引 [0]`，确认 `Source Name` 是要编辑的网格组件。
2. 展开组件的 **Override**。
3. 需要改变区域倍率时，勾选图 **②** 的 **覆写区域宽度倍率**。
4. 展开图 **③** 的 **Values**，修改其中的 **区域宽度倍率 / Local Scale**，例如 `0.8`。
5. 观察右视口，并检查顶部是否有参数校验错误。

**只修改 Values、不勾覆写开关，仍然继承上一级数值。** `Override Width` 替换基础宽度；“覆写区域宽度倍率”替换 Local Scale。

图 **④** 提供更细入口：

- **Materials**：按稳定的 `Material Slot Name` 匹配槽位；已有对应规则时编辑该规则，避免重复创建同名规则。
- **Sections**：填写真实 LOD / Section 索引；当前仅支持单 LOD 且独占材质槽的 Section。

继承顺序是 `Actor → Component → Material Slot → Section`，最深层已勾选字段生效，区域倍率不逐层累乘。演示角色部分既有材质规则用于关闭不支持的描边覆盖，查看宽度入口时可保留。

## 4. 对比画面和灯光

总览图 **④** 的左视口保留原表面，右视口在相同表面上叠加 Outline，两边共享相机和灯光。

- **聚焦当前角色 / Focus**：同步到全身构图。重复聚焦同一构图时画面可以不变，顶部仍显示结果。
- **标准 / 暖光 / 侧光**：同时改变两边的预览照明，不修改关卡灯光或风格参数。
- 骨骼预览为参考姿势；动画跟随效果在实际关卡中查看。

## 5. 应用预设并保存

![预设来源、重新应用、保存路径和关卡保存](Guide/04-preset-save.png)

[查看未标注原图](Guide/Raw/01-overview.jpg)

1. 图 **①** 的 **已应用预设（只读引用）** 只记录来源。
2. 在图 **②** 选择预设资产，会立即应用基础参数；再次应用同一资产时点击 **重新应用所选预设**。
3. 图 **③** 输入保存包路径，例如 `/Game/NPR/Outline/Presets/OP_MyOutline`。
4. 点击 **保存基础预设与当前关卡**，检查顶部结果。已有同名 Outline 预设会被更新。

基础风格写入预设资产；组件引用、Scope 与局部规则保存在关卡。应用基础预设后，已勾选的局部覆写继续参与最终效果。

图 **④** 的 **重新读取当前角色绑定** 重读当前内存配置并重建预览，不从磁盘重开关卡。检查磁盘恢复情况时，需要保存后正常关闭并重新打开项目与关卡。

## 6. 导出图片并找到文件

![导出结果、PNG 按钮与打开目录入口](Guide/05-export.png)

[查看未标注原图](Guide/Raw/05-export.jpg)

1. 点击图 **②** 的 **导出双视口 PNG**。
2. 图 **①** 顶部结果显示文件名和实际目录。
3. 点击图 **③** 的 **打开上次导出目录**。

每次在 `Saved/NPR/Outline/Previews/<时间戳>/` 新建独立目录，包含 `Original.png` 和 `Outline.png`。截图中的时间目录是一次实际导出的示例。

## 7. 关闭或重新启用描边

![关闭状态下的 Enabled 与启用按钮](Guide/06-disabled.png)

[查看未标注原图](Guide/Raw/06-disabled.jpg)

点击 **关闭角色描边（保留配置）** 后，图 **①** 的 Enabled 取消，右侧保留原表面。图 **②** 按钮变为 **启用角色描边**，点击即可恢复；需要保留开关状态时保存关卡。

## 操作后没有明显变化时

先看左栏顶部结果，再检查：

| 情况 | 原因与处理 |
|---|---|
| 重新收集显示新增 0、移除 0 | 组件没有增减，画面不变是正常结果 |
| 想重新应用相同预设 | 点击“重新应用所选预设” |
| 修改 Values 无变化 | 检查对应覆写开关，以及更深层规则是否覆盖该字段 |
| 灰色 Vertex / Mask 入口 | 当前 Screen 不支持该类连续宽度控制 |
| 参数已应用却没有线条 | 检查 Enabled、Method=None、宽度或倍率是否为 0，以及顶部错误 |
| 聚焦、读取、保存后画面不变 | 根据顶部提示确认是否完成，这些操作不一定改变渲染结果 |

更多按钮细节见 [按钮说明与修复](按钮说明与修复.md)。
