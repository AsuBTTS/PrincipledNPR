# Rim Light 边缘光

## 功能概述

我们用边缘光来提亮角色接近轮廓的位置，让头发、衣服和背景更容易分开。这个功能通常把亮色画在物体表面；[Outline](./outline.md) 则主要在轮廓外侧画线。

## 实现状态与效果

**规划中**：我们已经设计了三个参数，还没有把它们接入材质，也没有提供可用的专用编辑界面。效果图待补；我们会在功能接通后补上实际画面对比。

## 参数说明

以下是设计参数。准确数值和范围由[参数参考](../principled/parameters.md)自动读取，当前没有底层 Shader 绑定。

| 参数 | 类型 | 默认值 | 硬范围 | 用途 |
| --- | --- | --- | --- | --- |
| RimGrazingAngleRad | 数值，弧度 | 0.13962634015954636 | [0, π/2] | 从轮廓向内覆盖多大角度；默认约 8° |
| RimEdgeHalfWidthRad | 数值，弧度 | 0.03490658503988659 | [0, π/2] | 亮暗边缘的过渡半宽；默认约 2° |
| RimPeakScale | 数值，线性亮度倍率 | 0 | [0, 无上限] | 边缘光的峰值强度 |

弧度是角度的另一种单位，π 弧度等于 180°。这里的“宽度”描述表面与视线之间的角度，不表示屏幕上的像素数。

## 渲染实现与依赖

计划依据表面法线（表面朝向）和观察方向计算边缘区域，再控制覆盖范围、过渡和强度。是否受灯光方向、阴影遮挡影响，需要单独制定规则。直接加到自发光上，并不会自动得到引擎的阴影遮挡效果。

当前契约把该功能列为独立外观模块；S58 表中的 Unsupported 仅表示不能直接映射为 ToonProfile 字段，并不表示永远无法实现。

## 使用流程与限制

目前不能在 Outline 窗口开启。可阅读参数设计，但修改 Draft JSON 不会改变画面。后续开发应先做独立材质实验，确认不同视角、曝光和遮挡下的结果，再接入风格与角色控制。不要直接照搬 lilToon 的数值范围。
