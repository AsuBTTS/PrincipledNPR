# 基础颜色

## 功能概述

我们用基础颜色来确定皮肤、头发和衣服的主要颜色。这个功能通常读取颜色贴图，再乘一个颜色值。以后我们希望通过统一入口完成换色；目前仍需在角色原有材质中调整。

## 实现状态与效果

统一颜色控制为**规划中**。我们目前继续使用角色已有的材质和贴图；Outline 的颜色只控制描边。我们会在统一颜色控制接通后补上换色前后对比图。

## 参数说明

| 输入 | 类型 | 默认值 / 范围 | 当前用途 |
| --- | --- | --- | --- |
| BaseColor | 材质表面颜色输入 | 由源材质提供，无插件统一数值 | Generic / Face / Hair 所需输入之一 |

当前契约没有已接通的统一“色相、饱和度、明度”参数，也没有对应的插件 Shader 参数。不能把源材质中的任意同名参数当作统一接口。

## 渲染实现

颜色仍由源材质决定。`UNPRStyleBindingComponent::ApplyPackage` 能把预先准备好的材质包应用到网格的材质槽，但不会自动分析或生成颜色算法。

## 使用流程

现阶段在 UE 原材质或材质实例中调整颜色，并按原工作流保存。要使用插件预制包，需先准备实际材质并设置槽索引，见[架构](../developer/architecture.md)。

## 限制与开发信息

不同材质使用的参数名和计算方式可能不同；透明度也由原材质负责。未来统一颜色控制应先约定颜色空间、叠加顺序和遮罩规则，保留源材质高级选项。来源为契约的 `materialProfiles.*.requiredInputs` 与 `NPRStyleBindingComponent.cpp`，见[参数来源](../principled/parameters.md)。
