# MatCap

## 功能概述

我们可以用 MatCap 快速添加金属感、柔和亮面或手绘反光。这个功能可以理解为“用一张球形光照贴图给模型上色”：根据表面在镜头里的朝向，从贴图中取颜色。

目前没有已定义的插件 MatCap 参数，因此不填写虚构默认值。纹理、强度、混合方式、遮罩和左右眼视差处理属于后续设计议题，需明确兼容方案后再加入契约。

## 渲染实现与依赖

计划作为独立外观模块，使用法线和镜头方向产生贴图坐标，并与表面颜色混合。混合发生在何处、是否受实际灯光与阴影影响，目前尚未确定。

## 使用流程、限制与开发信息

当前没有开启流程。已有角色材质若自带类似效果，应继续使用其原有工具。后续先验证镜头旋转、法线贴图、透视和曝光，再定义统一视觉参数。不要将 MatCap 当作真实环境反射或默认拥有阴影遮挡。架构边界见[开发者指南](../developer/architecture.md)，参考算法证据见[lilToon 对照](../reference/liltoon-comparison.md)。
