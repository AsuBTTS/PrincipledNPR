## 我们做到哪一步了

我们已经接通 Outline 的主要使用流程，可以对整角色和局部区域调整描边，并提供左右对比预览、预设保存和图片导出。完整 Principled 参数转换还在开发，边缘光和 MatCap 仍在规划中。我们会在每个功能页面说明当前能做什么、还缺什么，避免把设计目标写成已经完成的功能。
