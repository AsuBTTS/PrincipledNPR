# 快速开始

这页只带我们打开工程、找到 NPR 调制入口。具体效果怎么调，放在左侧“功能”目录下对应的页面里说明。

1. 按[安装与环境](./installation.md)准备 UE 工程、插件和编译环境。
2. 打开 `PrincipledNPR.uproject`。第一次使用或源码有变化时，先完成编辑器目标的编译。
3. 在 UE 菜单中打开 **窗口 → NPR 调制**。
4. 顶部 **NPR 调制** 打开总览，页面内按后处理/非后处理查看效果；顶部较小的 **Outline**、**Rim Light** 进入编辑页。按本文档左侧“功能”目录阅读对应的算法与限制。
5. 需要保存的设置按功能页面说明保存。预设、关卡或其他资产的保存方式可能不同。

我们会在功能页区分当前可用、待验证和规划中的内容。打开一个页面前先看它标明的状态，避免把设计中的选项当成现有功能。

实际载入角色、局部调整、保存与导出的完整步骤见[NPR调制插件使用说明](../guides/NPR调制插件使用说明.md)。
