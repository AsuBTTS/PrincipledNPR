# 编辑器架构与操作

当前窗口操作已合并到[NPR调制插件使用说明](../guides/NPR调制插件使用说明.md)，包括角色选择、材质槽隔离、覆写、预览、保存、重开与常见问题。

Outline 和 Rim 都有实际编辑入口。Rim 提供槽位卡片、实时角色预览、隔离、原材质对比和 Profile/角色绑定保存；总览分类与操作见[统一效果工作区](../guides/npr-workspace.md)。算法分别见 [Outline](../outline/outline_introduction.md) 和 [Rim Light](../rim/rim_light_introduction.md)。
