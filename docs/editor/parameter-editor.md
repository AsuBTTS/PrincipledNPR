# 参数编辑与双视口

我们目前通过这个窗口调整 Outline 描边。打开 **Window → Principled NPR Outline** 后，左边看原材质，右边看当前描边。两个预览使用相同的相机和灯光，方便我们判断参数变化带来的效果。

## 选择目标

“使用关卡选中角色”读取关卡大纲中唯一选中的 Actor。“创建 / 打开角色级配置”进入整角色模式，区域设置放在 `Meshes` 下。预览中点击模型不等于选中了关卡 Actor。

旧单槽模式仍保留网格与材质槽选择、“转换 / 更新单槽 Outline 绑定”和恢复原材质。整角色模式无需先做单槽转换。

## 调整参数

字段变灰通常表示当前描边方法不适用，或尚未勾选覆写。Override 就是“用这一层的值替换继承值”；只有勾选对应开关后，`Values` 中的值才参与替换。宽度单位按方法分别为 cm 和 px，不能混用。

Actor 总开关控制整个角色；局部 Enabled 和 Method=None 可关闭区域。需要不同区域颜色或宽度时选择 IndependentRegions（独立区域）。UnifiedSilhouette（统一外轮廓）要求全组样式一致，只允许局部关闭。

窗口使用 UE Details 面板显示 C++ 属性的分组、依赖和高级参数，再通过 Validate 和 RefreshOutline 检查能否应用。灰色控件不是唯一校验：程序或脚本传入非法组合也应明确报错。

## 预览、导出与保存

“聚焦当前角色”同步双视口相机；Studio/Warm/Raking 分别提供标准、暖光和侧光观察。灯光按钮只改预览，不修改关卡灯光。角色预览使用参考姿势，不用于证明动画正常。

“导出双视口 PNG”每次创建独立时间目录；导出后可打开上次目录。导出图片不会代替[保存预设与关卡](./presets.md)。角色模式关闭描边时保留规则；旧单槽恢复则移除该槽绑定。

实现入口为 `NPROutlineEditorUI.cpp` 的 `UseSelection`、`ConfigureActor`、`LoadPreset`、`Save` 和窗口构造。完整原始文件可从[参数页](../principled/parameters.md)读取。当前基础流程有历史验证；本次未操作 UE 窗口。
