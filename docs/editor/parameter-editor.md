# 编辑器架构与操作

我们把不同外观功能放进同一个 **NPR 调制**入口，方便使用者在一个窗口里选角色、改参数、查看结果。窗口负责交互和预览；角色设置由 Runtime 组件保存和解析；真正画出效果的仍是各自的 UE 材质和渲染资源。

## 窗口、设置和渲染怎样配合

使用者在 `NPREditor` 窗口中调节并预览 → `NPRRuntime` 保存角色设置、解析 Actor / 组件 / 材质槽 / Section 的局部覆写 → Outline 走反向壳材质或屏幕空间后处理材质。编辑器保存工具会把基础设置存成预设，把角色局部设置保存在关卡中；Principled 风格档案到材质参数的完整自动映射仍在开发。

上面的 Outline 路径已经可以独立工作。Principled 风格/材质档案和后端材质绑定也有基础代码，但把所有视觉参数自动换成各后端数值的完整流程还没接通；不能把这两条路径当成同一套已完成的系统。

源码按职责分为两个 UE 模块：`NPREditor` 提供窗口、Slate 控件和保存入口；`NPRRuntime` 保存参数结构、管理角色组件并把解析后的设置传给描边材质。简单说，Slate 是 UE 编辑器里搭界面的工具；Runtime 是实际运行时也能使用的插件模块。主要代码入口见[模块架构](../developer/architecture.md)。

## 打开窗口和选择角色

在关卡大纲中选中一个角色，然后打开 **窗口 → NPR 调制**。点击“使用关卡选中角色”，再点“创建 / 打开角色级配置”。窗口读取这个角色使用的静态网格或骨骼网格组件。预览中点击模型不会自动选中关卡里的角色。

窗口顶部可以切换功能页。目前 Outline 提供可用的角色设置与预览；Rim Light 页是占位说明，不会改变材质或画面。Outline 的完整操作见[Outline 描边](../features/outline.md)。旧的 OpenEditor 脚本入口仍保留，并会打开同一个窗口。

## 角色设置和局部覆写

Outline 配置由角色级基础设置和区域覆写组成。角色总开关控制整组描边；`Meshes` 中每项对应源组件；材质规则按稳定的材质槽名查找；Section 规则只在单 LOD 且独占材质槽时有效。参数的继承顺序是 Actor、Component、Material Slot、Section。只有勾选的字段替换上一级；最深层勾选的值生效。`Override` 意思是“在这一层替换继承值”。

展开组件会看到真实材质槽卡片，包含槽编号、名称、材质和当前支持状态。“描边”控制是否启用该槽，“隔离”只在当前预览中显示该槽；它们不会改源网格或关卡组件的可见性。点击“编辑参数”展开局部设置，“恢复继承”删除本槽所有覆写。已有规则再次展开查看时不会重置；首次打开没有规则的槽，系统会建立一条继承规则。

需要不同区域样式时用 IndependentRegions（独立区域）；UnifiedSilhouette（统一外轮廓）要求整组参数一致，只允许局部关闭。Screen Space 和反向壳可调的参数并不完全相同，界面会按方法显示适用字段。更详细的调节流程和实际界面图在[Outline 页面](../features/outline.md)。

## 预览和保存

窗口默认只显示当前描边。勾选“原材质对比”后会并排显示原材质和描边结果，两侧相机和预览灯光保持一致。“聚焦当前角色”同步相机；Studio、Warm、Raking 用来从不同光线方向检查画面，这些按钮只影响预览，不改变关卡灯光。预览使用参考姿势，不能证明动画中的效果正常。

“导出双视口 PNG”会保存当前两侧画面，每次放到独立时间目录中。“打开上次目录”可以查看最近一次导出。图片不会替我们保存工程数据：基础 Outline 设置需要保存为[预设](./presets.md)，角色的局部规则要随当前关卡保存。预设只记录基础描边设置，分享完整角色配置时还需提供关卡/角色配置及引用资产。

2026-10-20 已在 UE 5.8.3 / Windows 的当前角色中检查功能页切换、材质槽隔离、参数展开、原材质对比和窄窗口布局。新增操作的范围及未覆盖项目见[材质槽界面验证记录](/generated/source/Documentation/Outline/MaterialSlotUI.md.txt)；这项界面检查不代替渲染算法的图像验收。
