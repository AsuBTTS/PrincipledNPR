# Principled 参数：我们希望美术直接说清楚画面

我们想做的，是让美术先选择“画面要怎么变”，再由系统决定该用哪些底层材质参数来实现。比如，明暗交界要往哪边移动、高光要铺多大、边缘光要向角色里面延伸多少。使用者不必先记住不同材质节点和算法各自的名字。

这样做不是把所有材质都变成同一种算法。相同的视觉控制可以在不同渲染方式里用不同办法实现；系统需要说明这种对应关系和它的限制。比如，屏幕上的像素宽度和模型外扩的厘米数会随相机和距离产生不同结果，不能直接当成同一个数值。

## 目前做到哪里

参数体系目前状态为**开发中**。我们已经整理出一份参数草案和示意图，用来讨论这些控制应该表达什么。图里的变化只是帮助我们交流设计方向，不是 UE 中的实测效果；完整的统一参数转换和渲染接入还没有完成。现在已经能单独使用的 Outline 走自己的设置链路，尚未自动接入这份统一参数体系。Rim Light、MatCap 等功能也要以各自页面标出的状态为准。

![Principled NPR 参数沿各自建议范围变化的概念示意图；不是 UE 实测画面](/images/principled-parameter-chart.svg)

图中数值用于说明参数方向，不代表各功能已经完成，也不代表不同后端会得到完全一样的画面。我们会按实际实现逐步补齐验证结果和映射说明。
